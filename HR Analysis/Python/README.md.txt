# HR Employee Attrition Analysis using Python

## Project Overview

This project analyzes an HR Employee Attrition dataset using Python to identify the major factors influencing employee turnover. The analysis focuses on understanding attrition patterns, exploring employee demographics, and providing business recommendations that can help organizations improve employee retention.

---

## Business Problem

Employee attrition is costly for organizations. High turnover leads to increased recruitment costs, loss of experienced employees, reduced productivity, and lower employee morale.

This project investigates the drivers of attrition and identifies areas where management can improve employee retention.

---

## Objectives

- Explore the HR dataset using Python
- Clean and validate the data
- Perform exploratory data analysis (EDA)
- Visualize employee attrition patterns
- Generate business insights
- Provide recommendations to reduce employee turnover

---

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## Dataset Information

- Total Employees: 1470
- Employees Left: 237
- Employees Stayed: 1233
- Attrition Rate: 16.12%

---

## Analysis Performed

- Overall Attrition Analysis
- Department Analysis
- Job Role Analysis
- Age Group Analysis
- Salary Band Analysis
- Business Travel Analysis
- Overtime Analysis
- Marital Status Analysis
- Gender Analysis
- Job Satisfaction Analysis
- Environment Satisfaction Analysis
- Work-Life Balance Analysis
- Years at Company Analysis
- Total Working Years Analysis

---

## Key Findings

- Sales Representatives recorded the highest attrition rate.
- Employees working overtime were significantly more likely to leave.
- Younger employees experienced higher turnover.
- Lower-income employees showed higher attrition.
- Sales Department experienced the highest employee turnover.
- Employees with poor work-life balance were more likely to resign.

---

## Business Recommendations

- Improve work-life balance initiatives.
- Review overtime policies.
- Strengthen employee engagement for younger employees.
- Improve career growth opportunities.
- Review compensation for lower-income employees.
- Focus retention strategies on Sales roles.
